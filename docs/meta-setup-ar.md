# ربط بيكسل Meta والكتالوج

معرّف البيكسل المطلوب: `1653262302473362`.

## التشغيل المحلي

شغّل `npm run dev` من مجلد `mithaly-backend`، ثم شغّل `npm run dev` من مجلد `mithaly-app` في نافذة أخرى. يجب أن تكون قاعدة PostgreSQL المحلية متاحة كما هو مضبوط في بيئة الباك إند.

- الموقع: http://localhost:3000
- الإدارة: http://localhost:3000/admin
- ملف XML المحلي: http://localhost:3000/facebook-feed.xml
- ملف CSV المحلي: http://localhost:3000/facebook-feed.csv

البيكسل الأساسي موجود بالفعل في التخطيط العام. لا تلصق نسخة إضافية من الكود؛ تكرار التثبيت قد يكرر الأحداث. يستخدم المتجر ولوحة الإدارة المعرّف نفسه من `src/lib/meta-pixel.ts`، مع أولوية المتغير `NEXT_PUBLIC_FACEBOOK_PIXEL_ID`.

## رفع منتجات الموقع إلى كتالوج Meta

1. افتح Commerce Manager واختر الكتالوج المقصود، أو أنشئ كتالوج منتجات عند الحاجة.
2. افتح مصادر البيانات، ثم أضف المنتجات باستخدام ملف بيانات / Data feed.
3. اختر رابطًا مع تحميل مجدول، وأدخل `https://the-vitahub.com/facebook-feed.xml`.
4. اختر التحديث اليومي وحدد العملة `EGP` إذا طُلبت، ثم ابدأ الاستيراد. يمكن استخدام `https://the-vitahub.com/facebook-feed.csv` كبديل للمصدر نفسه.
5. من مصادر الأحداث / Events اربط الكتالوج بالبيكسل `1653262302473362`. قد تختلف أسماء القوائم بحسب واجهة حسابك.
6. راجع نتيجة الاستيراد والأخطاء، ثم اختبر مشاهدة منتج وإضافته للسلة في Events Manager ← Test Events. قارن `content_ids` بمعرّفات المنتجات في الكتالوج.

لا تستخدم رابط localhost للاستيراد المجدول؛ Meta يحتاج رابطًا عامًا يمكنه الوصول إليه. لا تضف XML وCSV كمصدرين متكررين لنفس المنتجات.

إذا كان المقصود إضافة منتجات إلى الموقع نفسه، فلوحة الإدارة تحتوي على استيراد ملف Excel ضمن قسم المنتجات؛ هذا إجراء مختلف عن ربط كتالوج Meta.

## قبل النشر

اضبط `NEXT_PUBLIC_FACEBOOK_PIXEL_ID=1653262302473362` في بيئة الاستضافة وقت البناء، ثم أعد بناء الواجهة ونشرها. المتغيرات العامة تثبت في ملفات المتصفح أثناء البناء. عند استخدام Docker مرّر المعرّف نفسه ضمن متغيرات البناء والتشغيل.

## نتيجة الفحص في 26 أكتوبر 2026

- الواجهة والباك إند اشتغلا محليًا على المنفذين 3000 و5000، مع اتصال PostgreSQL و140 منتجًا.
- الصفحة المحلية تتضمن معرّف البيكسل الجديد ولا تتضمن القديم؛ ملفات XML وCSV المحلية أعادت HTTP 200، وXML يحتوي على 140 معرّفًا مختلفًا.
- تمت تجربة مشاهدة منتج وإضافته للسلة؛ ظهر المنتج وسعره 1600 جنيه داخل السلة. لم يتم إنشاء طلب شراء.
- نجحت اختبارات تتبع Meta الخمسة واختبارات الكتالوج الستة وفحص TypeScript وبناء الإنتاج. فحص ESLint للتخطيط والإعداد المشترك انتهى دون أخطاء، مع تحذير استخدام img لصورة البيكسل ذات حجم 1×1.
- المصدر المنشور `https://the-vitahub.com/facebook-feed.xml` أعاد HTTP 200 و221 معرّفًا مختلفًا، وCSV أعاد HTTP 200. صورة عينة واحدة من الكتالوج المنشور أعادت JPEG بقياس 1024×1024؛ هذا ليس فحصًا لكل الصور.
- الموقع المنشور ما زال يتضمن المعرف القديم `2785073648526058` وقت الفحص المحلي. لم تُنشر التغييرات أو يتم تأكيد استقبال الأحداث أو استيراد الكتالوج من داخل حساب Meta أثناء هذا الفحص المحلي.
